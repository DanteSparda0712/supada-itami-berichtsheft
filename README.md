# Supada Itami Berichtsheft

Statische Webseite für Supada Itami, Bestätigter Genin in Zenkai DE. Enthalten sind vier ausgearbeitete Musterberichte zu Taijutsu, Raiton, Chakra-Kontrolle und der Unterstützung von Akademieschülern.

Die Seite funktioniert ohne Installation oder Build-Schritt. Alle benötigten Dateien liegen direkt im Hauptverzeichnis. Suche, Themenfilter, Farbschema, Textdownload und Druckansicht funktionieren im Browser.

## Veröffentlichung mit GitHub Pages

Die Dateien in ein Repository übertragen. Unter **Settings → Pages → Build and deployment** die Quelle **Deploy from a branch**, den Branch **main** und den Ordner **/(root)** auswählen. Die Datei `.nojekyll` ist bereits enthalten.

Die Texte sind fiktive Musterberichte für Rollenspiel.
